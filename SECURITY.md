# Security

This is a research preview with no production support or security audit claim.
All releases before a declared stable milestone are experimental. The native
regtest signer uses public disposable keys and must never hold real funds.

For a potentially exploitable issue, use GitHub's **Report a vulnerability** entry
on this repository's Security page. Avoid public reports containing an exploit
against a live wallet or service. Include a minimal disposable reproducer, affected
commit, expected behavior and observed behavior. Never include real wallet secrets
or private user data. There is no promised response time.

Protocol interpretation disagreements without exploit-sensitive details can be
reported as issues. The toolkit stops on documented unresolved cases; replacing
that unavailable state with a guessed balance is not a safe workaround.
